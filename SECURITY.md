# Security Policy

## Reporting a Vulnerability

We take the security of Kletia very seriously. If you discover a vulnerability, please report it via email to **security@kletiaai.xyz**.

### Scope
The following components are **in scope**:
- Smart contracts (Base Mainnet, Arbitrum One)
- API endpoints and backend services
- Frontend application security
- Zero-knowledge (ZK) circuits and intent parsing infrastructure

### Out of Scope
The following are **out of scope**:
- Testnet-only features and mock implementations (Arc Testnet, Stellar Testnet)
- Third-party dependencies and upstream vulnerabilities (unless directly exploitable via our configuration)
- Theoretical attacks without actionable exploit paths

### Response Timeline
- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Triage:** We will triage the vulnerability and communicate our assessment within 7 days.

### Bug Bounty
A formal bug bounty program is currently being evaluated. We deeply appreciate community members who report security issues responsibly.
